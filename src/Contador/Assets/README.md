# Recurso visual

pirate-shop-token.png es la imagen proporcionada por el usuario para el diseño pirata de Contador. Se integra como Resource de WPF, no como archivo externo necesario para ejecutar la app.

Contador.ico deriva de esa misma imagen y contiene versiones PNG de 16, 24, 32, 48, 64, 128 y 256 píxeles. Se usa como ApplicationIcon, icono de la ventana y recurso embebido del motor para dibujar la moneda del overlay con transparencia.

La imagen y las marcas del juego pertenecen a sus respectivos titulares; no se presentan como una ilustración original del proyecto ni como contenido sujeto a la licencia MIT del código.
