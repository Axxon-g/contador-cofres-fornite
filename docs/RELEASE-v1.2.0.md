# Contador 1.2.0 — Rumbo al botín

- Aviso «EN PARTIDA» en el launcher y el overlay mediante sondeo de cabeceras cada dos segundos, independiente del análisis pesado y de la pausa del contador.
- Overlay con etiquetas explícitas: estado, última partida, esta sesión y tesoros.
- Sesión corregida: no incluye importaciones ni repeticiones antiguas; el mismo filtro se usa en la ventana, informe y overlay.
- Nueva paleta pirata azul marino, rojo y dorado, con moneda integrada en el ejecutable.
- Se conserva la importación automática de historiales con respaldo y sin duplicados.

Descarga **Contador.exe** y ábrelo. No necesita instalar .NET ni scripts. Activa las repeticiones en Fortnite; los cofres se cuentan después de cada partida, cuando termina de escribirse la repetición.

El aviso de partida requiere una repetición activa que Fortnite haya escrito recientemente. Una repetición abandonada no mantiene indefinidamente el aviso. Esta versión no lee la memoria del juego.
