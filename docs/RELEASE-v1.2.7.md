# Contador 1.2.7 · Filtro de fechas

- Calendarios Desde y Hasta en Ajustes, con días completos incluidos.
- Acceso rápido Desde 01/11/2026, sin fecha final para seguir contando nuevas partidas.
- Todo el historial permite quitar el filtro sin borrar registros.
- El período se guarda y se comparte entre resumen, historial, selector de cuentas, informe, CSV y overlays.
- Los rangos invertidos se rechazan con un mensaje junto a los calendarios.

Cierra la aplicación y reemplaza Contador.exe. Tu historial se conserva. Después abre Ajustes → Fechas del contador y pulsa Desde 01/11/2026.

El filtro usa la fecha local de inicio de la partida; si falta en un registro antiguo, usa su fecha de análisis. No se eliminan partidas y no se recuperan las que no estaban guardadas.

Esta nueva compilación tiene otro SHA-256: el informe anterior de VirusTotal no corresponde a este archivo. El ejecutable continúa sin firma digital de editor verificado.
