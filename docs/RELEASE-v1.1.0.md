# Contador 1.1.0 — Historial integrado

Aplicación de escritorio para contar tus cofres de Fortnite a partir de las repeticiones de Battle Royale.

## Descargar y empezar

1. Descarga **Contador.exe** en los archivos adjuntos de esta versión.
2. Activa **Grabar repeticiones** en Fortnite.
3. Abre la app y déjala funcionando mientras juegas.

El ejecutable es autónomo para Windows 10/11 x64: no requiere instalar .NET ni ejecutar scripts. Los cofres se suman después de finalizar la partida.

## Incluye

- Resumen de total, sesión, última partida, media y récord.
- Historial con búsqueda, ordenación, detalles y exportación CSV.
- Perfiles separados por cuenta.
- Overlay con controles de tamaño, bloqueo y visibilidad.
- Importación automática de los historiales locales de ChestCounter y ChestTracker, con respaldo y sin duplicados.

La app conserva el registro del analizador más reciente para las partidas compartidas. Los archivos de las aplicaciones anteriores no se modifican.

## Verificación y límites

Pasaron 28 comprobaciones, incluyendo importación y reapertura sobre una copia de historial real. Las repeticiones incompletas o incompatibles pueden no contarse; las actualizaciones de Fortnite pueden requerir actualizar el lector.

Los archivos Source code son para desarrollar. Para usar Contador, elige **Contador.exe**.
